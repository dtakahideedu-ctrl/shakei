# 射形分析帳（ウェブ版）

正面と馬手側から撮った動画と矢所の写真から、骨格と矢を重ねて射法八節ごとに射形を測る、部内用のウェブアプリです。「手の内・ひねり」モードでは、弓手と馬手を別々に接写した動画から、角見や手の内の回り、馬手の捻りと離れでの動きを測ります。部の合言葉を知っている人が、それぞれのスマホから登録し、同じ記録を見られます。Claude のアカウントは要りません。

| 部品 | 役割 | 置き場所 |
| --- | --- | --- |
| アプリ本体 | 画面、骨格の解析（各自の端末の中）、立体表示 | GitHub Pages（このフォルダ） |
| サーバー | 合言葉の確認、記録の保存と読み出し、AI 講評 | Google Apps Script（`gas/Code.gs`） |
| 記録 | 射ごと・手の記録ごとの設定・矢所の印・講評 | Google スプレッドシート「射形分析帳データ」 |
| 骨格データと画像 | 解析結果、縮小したコマ画像、矢所の写真 | Google ドライブのフォルダ「射形分析帳データ」 |

準備は全部で 20〜30 分ほどです。順番に進めてください。

---

## 1. サーバーを作る（Google Apps Script）

1. 記録を置きたい Google アカウントで <https://script.google.com> を開き、「新しいプロジェクト」を押します。左上の「無題のプロジェクト」を押して、名前を「射形分析帳サーバー」にします。
2. 最初からある `コード.gs`（`Code.gs`）の中身をすべて消し、このフォルダの `gas/Code.gs` の中身を貼り付けて保存します（Ctrl+S / ⌘+S）。
3. 貼り付けたコードの上の方にある `SETTINGS` に、次を書きます。

   | 項目 | 書くこと |
   | --- | --- |
   | `VIEW_KEY` | 閲覧の合言葉。結果を見るだけの人（保護者、OB など）に渡す |
   | `EDIT_KEY` | 登録の合言葉。動画や写真を登録する部員に渡す |
   | `ADMIN_KEY` | 管理の合言葉。記録を消せる。管理する人だけが持つ |
   | `CLUB_NAME` | 画面に出す名前（例: `〇〇高校弓道部`）。空でもよい |
   | `ANTHROPIC_API_KEY` | AI 講評を使う時だけ（4 章）。使わないなら空のまま |

   合言葉は 3 つとも別のものにし、それぞれ 6 文字以上にします。
4. 上の関数の選び欄で `setup` を選び、「実行」を押します。
   - 初めての時は「承認が必要です」と出ます。「権限を確認」→ 自分のアカウントを選ぶ → 「このアプリは Google で確認されていません」と出たら「詳細」→「射形分析帳サーバー（安全ではないページ）に移動」→「許可」と進みます。自分で作ったスクリプトに、自分のスプレッドシートとドライブを使う許可を出すための画面です。
   - 実行ログに「設定しました」と出れば完了です。Google ドライブに、スプレッドシートとフォルダ「射形分析帳データ」ができます。
5. 右上の「デプロイ」→「新しいデプロイ」を押し、「種類の選択」の歯車から「ウェブアプリ」を選びます。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**（「Google アカウントを持つ全員」ではありません。そちらにするとアプリからつながりません）
   - 「デプロイ」を押し、表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/……/exec`）をコピーしておきます。
6. 確かめ: その URL をブラウザで開いて「射形分析帳のサーバーは動いています。」と出れば成功です。
7. 合言葉と API キーはサーバーの内部（スクリプト プロパティ）に保存されました。`SETTINGS` に書いた値は消して保存しておくと安全です（特に API キー）。

## 2. アプリを公開する（GitHub Pages）

1. GitHub で新しいリポジトリを作ります（例: `shakei`）。無料のプランで GitHub Pages を使うには「Public」にします。コードは誰でも見られますが、合言葉と API キーは入っていません。
2. このフォルダの `config.js` をテキストエディタで開き、`apiUrl: ''` の `''` の中に 1 章でコピーした URL を貼って保存します。

   ```js
   window.SHAKEI_CONFIG = {
     apiUrl: 'https://script.google.com/macros/s/……/exec'
   };
   ```
3. リポジトリの画面で「Add file」→「Upload files」を押し、このフォルダの中身（`index.html`、`app.js`、`core.js`、`config.js`、`models` フォルダ、`gas` フォルダ、`README.md`）をまとめてドラッグし、「Commit changes」を押します。
   - **合言葉や API キーを書いたままの `Code.gs` は上げないでください。** このフォルダの `gas/Code.gs` は空欄のままなので、そのまま上げて問題ありません。
4. リポジトリの「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を「main」と「/(root)」にして「Save」を押します。
5. 数分待つと `https://<GitHubのユーザー名>.github.io/shakei/` でアプリが開きます。

## 3. 部員に伝える

- アプリの URL と、登録の合言葉（見るだけの人には閲覧の合言葉）を伝えます。
- 初めて開いた時に、合言葉と名前を入れます。名前は「〇〇が登録」の表示に使います。合言葉と名前は、その端末に記憶されます。
- 1 射ごとに、誰か 1 人が「＋ 新しい射」を押します。正面・馬手側・矢所を撮った人が、それぞれの端末から自分の枠に登録します。ほかの人の登録は、約 5 秒以内に全員の画面に届きます。

## 手の内・ひねりモード

画面の上の「手の内・ひねり」に切り替えると使えます。射形の記録とは別に「手の記録」として保存され、弓手と馬手を撮った人が、それぞれの端末から登録できます。

- **撮る位置**: 弓手は射手の正面（胸の側）から、馬手は射手の後ろ（背中の側）から、それぞれの手の高さで撮ります。カメラは三脚で水平に置き、**矢の通り道や的の側には決して置かないでください**。弓返りや残心で腕が伸びても当たらないよう、手から 1.5m 以上離してズームします。
- **馬手の目印**: 直径 1.5〜2cm の丸いシールを、ゆがけの甲の人差し指側に**黄**、小指側に**青**、手首に**緑**で貼ります。黄と青の間はおよそ 5cm にし、違う時は「設定と注意」の「目印の間隔」を直します。光らない紙のシールが追いやすいです。動画を選んだら、目印が見えるコマで黄 → 青 → 緑の順にタップしてから「解析する」を押します。
- **弓手**: 手の 21 点を自動で推定します（目印は要りません）。手が画面の真ん中にない時は、解析の前に手をタップします。
- **スロー撮影**: 離れの瞬間の回りの速さや、止まるまでの時間は、実時間で毎秒 120 コマ以上の撮影で測れます。毎秒 240 コマで撮って毎秒 30 コマで再生される動画は、枠の「時間の流れ」を「スロー ⅛」に、毎秒 120 コマなら「スロー ¼」にします。iPhone のスローは、写真アプリの「編集」でスローの範囲を動画全体に広げてから選んでください。
- 弓手と馬手は、それぞれの離れの瞬間で時刻をそろえて並べます。自動で見つけた離れがずれている時は「離れの位置を直す」で 1 コマずつ直せます（直した位置は全員に届きます）。

## 4. AI 講評を使う（任意）

計測の結果をもとに、Claude（Anthropic の AI）が講評の文章を作ります。使った分だけ料金がかかります。

1. Anthropic の Claude Console で API キーを作り、支払い方法を登録します（[Claude API の説明](https://platform.claude.com/docs/en/api/overview)）。
2. `Code.gs` の `SETTINGS` の `ANTHROPIC_API_KEY` にキーを書き、もう一度 `setup` を実行します。デプロイし直す必要はありません。終わったらキーを消して保存しておきます。
3. 登録の合言葉で入った人の「計測」欄に、「AIの講評を作る」ボタンが出ます。作った講評は、その射を見る全員に表示されます。

| 設定 | 意味 | 初めの値 |
| --- | --- | --- |
| `AI_DAILY_LIMIT` | 1 日に作れる講評の回数（全員の合計） | 30 |
| `AI_MODEL` | 使うモデル。費用を抑えるなら `claude-haiku-5-5` | `claude-sonnet-5-5` |

やめる時は、Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」で `ANTHROPIC_API_KEY` を削除します。

## 合言葉を変える

`SETTINGS` に新しい合言葉を書いて `setup` を実行し直します。デプロイし直す必要はありません。部員は次に開いた時に、新しい合言葉を入れ直します。合言葉が外に漏れた時も、この方法で変えてください。

## コードを直した時

- **サーバー（Code.gs）**: 保存したあと「デプロイ」→「デプロイを管理」→ 鉛筆のボタン → バージョンを「新バージョン」にして「デプロイ」。こうすると URL は変わりません（「新しいデプロイ」にすると URL が変わります）。
- **アプリ**: GitHub で、直したファイルを同じ名前でアップロードし直します。

### 前の版から「手の内・ひねり」の入った版に上げる時

1. Apps Script の `Code.gs` の中身を、この版の `gas/Code.gs` にすべて貼り替えて保存します。`SETTINGS` は空欄のままで構いません（合言葉と API キーはスクリプト プロパティに残っています）。`setup` を実行し直す必要もありません。
2. 上のとおり「デプロイを管理」→ 鉛筆 →「新バージョン」でデプロイします。URL は変わりません。
3. GitHub に `index.html`・`app.js`・`core.js`・`gas/Code.gs`・`README.md` と、`models` フォルダの `handlandmark-full.json`・`handlandmark-full.bin` をアップロードします。`config.js` は前のもののままで構いません（上書きした時は、サーバーの URL を書き直します）。
4. これまでの射の記録はそのまま使えます。

## 知っておいてほしいこと

- **合言葉は部内向けの鍵です。** 知っている人なら誰でも記録と縮小した映像を見られます。公開の範囲は、射手本人の了承をとって決めてください。合言葉を 60 回ほど続けて間違えると、10 分間すべての入室を受け付けなくなります。
- **無料の範囲**: Google Apps Script には、同時に動ける数や 1 日の実行時間などの上限があります。部活の規模なら通常は収まります。アプリは開いている間、数秒ごとにサーバーへ更新を確かめます（画面を閉じるか裏に回すと止まるか間隔が延びます）。
- **容量**: 1 射あたり、コマ画像と写真でおよそ 1〜2 MB をドライブに使います。手の記録は、スロー撮影だとコマが多くなるので 1 本あたり 2〜4 MB ほどです。古い記録は、管理の合言葉で入って「この射の記録を消す」で消せます（ドライブのゴミ箱に入ります）。
- **解析の限界**: カメラ 1 台ずつの平面の推定です。角度は数度、長さは数 cm 変わります。射形モードでは弓・矢・手の内は検出しません。2 本の動画の時刻合わせや八節の区切りがずれた時は、「区切りと時刻合わせを直す」で直してください。手の内・ひねりモードでも、手が画面に対して斜めに写ると角度は小さめに出ます。弓の陰に隠れる中指・薬指・小指は推定なので参考にとどめてください。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面 |
| `app.js` | 画面の動きと、サーバーとのやりとり |
| `core.js` | 骨格の解析と計測 |
| `config.js` | サーバーの URL（ここだけ書き換える） |
| `models/` | 姿勢推定のモデル（MoveNet）と、手の 21 点を推定するモデル（handlandmark-full） |
| `gas/Code.gs` | サーバーのコード（Apps Script に貼る） |
| `gas/appsscript.json` | Apps Script の設定（clasp を使う人向け。手で貼る時は不要） |

姿勢推定には MoveNet（Google、Apache License 2.0）、手の推定には MediaPipe Hands の手のランドマークのモデル（Google、Apache License 2.0）を、どちらも [@vladmandic/human-models](https://www.npmjs.com/package/@vladmandic/human-models) 版で使い、TensorFlow.js（Apache License 2.0）で動かしています。
